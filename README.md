# Lawrence Sheriff School 2027 Admissions Mission Control

A modern single-page planning web app for families preparing for Lawrence Sheriff School Year 7 entry (September 2027).

## Highlights

- UI refresh with a polished, conversion-focused layout inspired by modern UK property portals.
- Live countdown cards for exam start, registration close, CAF deadline, and National Offer Day.
- Visual admissions timeline through September 2027.
- 11+ weighting guide (50% English/VR, 25% NVR, 25% Maths).
- Interactive 6-month study checklist persisted in `localStorage`.
- Exact catchment reference section:
  - Priority Circle: 10.004 miles from Rugby Water Tower.
  - Eastern Area of Warwickshire place list.
- Property search helper with budget slider and quick links to Rightmove, Zoopla, and OnTheMarket.
- Browser notifications and `.ics` calendar export.
- Readiness score + deadline risk radar cards.
- Weekly revision split helper (hours auto-distributed 50/25/25).
- Parent notes/evidence vault text area persisted in local storage.

## Run

Open `index.html` in a browser.
